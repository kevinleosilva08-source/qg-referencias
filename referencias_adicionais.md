## FERRAMENTAS DE INSPEÇÃO E PROMPTS

### GetLayers — Extensão Chrome
- **URL:** https://getlayers.ai (Chrome Web Store)
- **O que é:** Extensão que inspeciona qualquer site e extrai CSS organizado, fontes, cores e assets com um clique. Tem MCP próprio para Claude Code
- **Gratuito:** sim
- **Quando usar:**
  - Inspecionar elemento de site de referência e trazer CSS para o QG
  - Identificar fontes e assets de sites premium
  - Claude Code com MCP lê elementos ao vivo e corrige automaticamente
- **Instalar:** Chrome Web Store → "GetLayers" → Add to Chrome

### GetLayers — Biblioteca de Templates
- **URL:** https://getlayers.ai
- **O que é:** 175+ templates, fundos 3D e seções animadas com prompt pronto para Claude Code
- **Gratuito:** plano gratuito com acesso limitado — usar apenas conteúdo gratuito

### MotionSites.ai
- **URL:** https://motionsites.ai
- **O que é:** Biblioteca de prompts premium para heroes animados e seções de landing page. Altamente estruturados — tipografia, hover states, motion, responsividade
- **Stack:** React + Tailwind — NÃO compatível com HTML/CSS/JS puro
- **Quando usar:**
  - ✅ Projetos React — portfólio pessoal, lojas virtuais React
  - ❌ Sites HTML/CSS/JS de clientes locais
- **Como usar:** escolher hero por categoria → copiar prompt → colar no Claude Code adaptando cores e conteúdo

## FERRAMENTAS ADICIONADAS

### Mobbin — mobbin.design
- **O que é:** Biblioteca de padrões UI/UX de apps e web products reais (Airbnb, Stripe, Notion)
- **Quando usar:** portfólio pessoal, lojas virtuais, projetos React com foco em produto digital
- **Não usar:** sites institucionais de clientes locais

### NamethatUI — namethatui.com
- **O que é:** Identifica nome técnico de componentes e elementos de UI
- **Quando usar:** quando ver um efeito e não saber o nome para buscar referências ou pedir ao Claude Code

### Napkin.ai — napkin.ai
- **O que é:** Transforma texto em diagramas, fluxogramas e infográficos com IA
- **Quando usar:** apresentações de proposta para clientes, fluxos de processo, mapas de serviços
- **Não é para criação de sites**

### Finsweet LottieFlow — finsweet.com/lottieflow
- **O que é:** Biblioteca gratuita de animações Lottie — ícones e elementos animados em JSON
- **Quando usar:** ícones animados em qualquer projeto via lottie-player

### Google Stitch + design.md — stitch.withgoogle.com
- **O que é:** Gera sistema de design com IA e exporta design.md com tokens
- **Veredicto:** pouca utilidade no fluxo atual — QG já define paleta e tipografia antes do Code

### Refero.design — refero.design
- **O que é:** Biblioteca de UI/UX de produtos SaaS organizados por categoria de tela
- **Quando usar:** portfólio pessoal, lojas virtuais, projetos React com foco em produto digital
- **Não usar:** sites institucionais de clientes locais

### Sketchfab — sketchfab.com
- **O que é:** Maior plataforma de modelos 3D interativos embedáveis com uma linha de código
- **⭐ REGRA:** todo projeto onde um elemento 3D agregar valor — arquitetura, marmoraria, produto físico — implementar embed do Sketchfab automaticamente
